# Personal AI Portfolio

This is a personal portfolio project for transitioning from C-end product management into AI product roles.

The project includes:

- A personal resume and portfolio website
- AI product prototype ideas
- Web coding experiments
- Product teardown notes
- Resume and career positioning materials
- Visual assets and personal creator links

## Current Positioning

I am a C-end product manager with an industrial design and UI design background. I am building this portfolio to show how my design taste, user empathy, product experience, and AI-assisted building workflow can translate into AI product work.

## Project Structure

```text
personal-ai-portfolio/
  README.md
  PROJECT.md
  ROADMAP.md
  CHANGELOG.md
  docs/
  resume/
  website/
  works/
  assets/
```

## Main Modules

- `website/`: the portfolio website source code
- `works/`: product briefs, prototype notes, case studies, and screenshots for each portfolio work
- `docs/`: global strategy, design direction, content rules, and transition notes
- `resume/`: resume files and resume-related notes
- `assets/`: photos, screenshots, brand materials, and visual references
