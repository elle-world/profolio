# AI Travel Planner

## Concept

An AI-assisted travel planning prototype that generates editable trip plans based on user preferences, constraints, and travel style.

## Why This Work

Travel is part of my personal context, but it should appear as a product scenario rather than the main identity of the portfolio.

This work can demonstrate:

- user empathy
- recommendation experience design
- preference collection
- editable AI output
- personal taste and lifestyle context
