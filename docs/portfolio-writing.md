# Portfolio Writing Guide

## Work Case Template

Each portfolio work should answer:

1. What problem does it address?
2. Who is the user?
3. Why is AI useful here?
4. What did I design or build?
5. What tools did I use?
6. What did I learn?
7. What would I improve next?

## Recommended Case Structure

```text
Title
One-line summary
Problem
Target user
My role
AI workflow
Product decisions
Prototype or screenshots
Reflection
Next steps
```

## Tone

The writing should be:

- specific
- honest
- structured
- product-minded
- easy for recruiters to scan

Avoid vague claims such as:

- passionate about AI
- familiar with AI tools
- strong learning ability

Replace them with concrete evidence:

- built a prototype
- analyzed failure cases
- redesigned a user flow
- compared AI output quality
- shipped a public web page
